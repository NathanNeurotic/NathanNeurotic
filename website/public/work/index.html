RiptOPL

RiptOPL is my downstream fork of Open PS2 Loader. What it adds:

  • A built-in PSBBN-style theme with List, Grid, Coverflow and PSBBN Flow views. Hold L3 to switch.
  • A Favorites tab.
  • Per-game launching through the Neutrino core.
  • A reorganized, category-based settings layout, stored in its own settings_riptopl.cfg so it doesn't clash with official OPL or wOPL.
  • DualSense support.

The main line is now C++ on the ps2build SDK. The original C codebase is still kept as the legacy edition.

Based on Open PS2 Loader by Ifcaro and jimmikaelkael, under the Academic Free License 3.0. Pull requests have come from techwritescode, belomaxorka, Ronnie Sahlberg, MrRexD, darkladark and others. The README credits every upstream author.

Launchstation

A PS2 dashboard, file manager and homebrew launcher, based on wLaunchELF_R3Z. You can browse devices, launch applications and game images, manage saves and memory card images, and back up MMCE cards locally or to Google Drive, all from the controller.

It has 18 built-in theme presets. They're compiled in, so there are no theme files to install.

Other people have forked it, and I review fixes from forks and credit them when they're merged. Official builds are only on the Releases page.

POPSLoader

A browser and launcher for PS1 games on a PS2. It supports the original POPStarter and Sony POPS setup with VCD images, and Gageformer's Ember core as a separate, experimental emulator. You browse by storage device, launch games, and manage settings and artwork.

The project was started by israpps (El_isra). I work on the interface and put out the releases.

POPStarter is by krHACKen. Passing automated builds doesn't prove a game or device works on real hardware, so the repo keeps a hardware status page.

PS2-Servers

Runs game and file servers for network-capable PS2 homebrew, so the console can load from your computer over the LAN. It comes in three editions:

  • Desktop: a launcher app, with a searchable game library, art conversion and a setup guide.
  • Core: the same Python servers, run from a terminal.
  • Edge: a separate Go server for routers, NAS boxes, Raspberry Pis and headless machines.

Pick the mode your loader supports. Running a server doesn't add that protocol to a PS2 app that doesn't have it.

Made in collaboration with FatBaldDad's PS2-EtherDrive.

Smaller projects

  • launcHER

    A small forwarder that finds Ember wherever you keep it, prepares that storage device, hands Ember the game to launch, and then gets out of the way. Derived from the standalone launcher in pcm720's OSDMenu.

  • Simple Media System

    A maintained fork of Eugene Plotnikov's SMS media player: video, music, pictures, subtitles and playlists. It adds MX4SIO, exFAT HDD, i.LINK, MMCE and UDPFS support, DS3/DS4 controllers, and a desktop media converter.
