Hi, I'm Nathan.

Also known as Ripto. I work on PlayStation 2 homebrew: a game loader, a dashboard, a PS1 game launcher, servers for loading games over your home network, and the guides that go with them. It's all open source.

RiptOPL

PS2 game loader · fork of Open PS2 Loader

My fork of Open PS2 Loader. It adds a PSBBN-style theme with List, Grid, Coverflow and PSBBN Flow views, a Favorites tab, per-game Neutrino launching, a reorganized settings layout and DualSense support.

Launchstation

PS2 dashboard and file manager · based on wLaunchELF_R3Z

A dashboard, file manager and homebrew launcher. Browse devices, launch apps and game images, manage saves and memory card images, and back up MMCE cards locally or to Google Drive. It has 18 built-in themes.

POPSLoader

PS1 game launcher for the PS2 · started by israpps

Browse and launch PS1 games on a PS2, using POPStarter and Sony's POPS, or the experimental Ember emulator core. israpps started the project; I work on the interface and put out the releases.

PS2-Servers

LAN game and file servers · Python and Go

Runs the servers a network-capable PS2 needs to load games and files from your computer. There's a desktop app, a terminal version, and an Edge build in Go for routers, NAS boxes and Raspberry Pis. Made with FatBaldDad's PS2-EtherDrive.
