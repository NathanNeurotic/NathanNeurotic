Hi, I'm Nathan.

Also known as Ripto. I make and maintain homebrew for the PlayStation 2: a game loader, a dashboard, a PS1 game launcher, network servers, and the guides that go with them. It's all free and open source, and bug reports are always welcome.

RiptOPL

PS2 game loader · fork of Open PS2 Loader

Open PS2 Loader with a PSBBN-style look: List, Grid, Coverflow and PSBBN Flow views, a Favorites tab, per-game Neutrino launching, a cleaner settings layout and optional DualSense support.

Launchstation

PS2 dashboard and file manager · based on wLaunchELF_R3Z

A dashboard, file manager and homebrew launcher. Browse your devices, launch apps and game images, manage saves and memory card images, and back up MMCE cards locally or to Google Drive. It comes with 18 built-in themes.

POPSLoader

PS1 game launcher for the PS2 · started by israpps

Browse and launch PS1 games on a PS2, through POPStarter and Sony's POPS or the experimental Ember emulator core. israpps started it; I work on the interface and put out the releases.

  • Source
  • Docs
  • Download

PS2-Servers

LAN game and file servers · Python and Go

The PC side of playing PS2 games over your home network. It runs SMB, UDPFS, UDPBD, NFS and HTTP servers on Windows, Linux or macOS, so the console can load games straight from your computer. There's also Edge, a separate Go server for routers, NAS boxes and Raspberry Pis.
