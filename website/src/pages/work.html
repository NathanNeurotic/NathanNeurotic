RiptOPL

RiptOPL is my downstream fork of Open PS2 Loader. What it adds:

  • A built-in PSBBN-style theme with List, Grid, Coverflow and PSBBN Flow views. Hold L3 to switch.
  • A Favorites tab.
  • Per-game launching through the Neutrino core.
  • A reorganized settings layout, grouped by category. Its main settings live in their own settings_riptopl.cfg, so they don't clash with official OPL or wOPL.
  • Optional DualSense support, as a separate build.

The main line is now C++ on the ps2build SDK, built together with techwritescode. The original C codebase lives on as the legacy edition.

Developed in partnership with akilluminati47's RIPPS2 project. Based on Open PS2 Loader by Ifcaro and jimmikaelkael, under the Academic Free License 3.0. Pull requests have come from techwritescode, belomaxorka, Ronnie Sahlberg, MrRexD, darkladark and others. The README credits every upstream author.

Launchstation

A PS2 dashboard, file manager and homebrew launcher, based on wLaunchELF_R3Z. You can browse devices, launch applications and game images, manage saves and memory card images, and back up MMCE cards locally or to Google Drive, all from the controller.

It comes with 18 built-in themes. They're compiled in, so there are no theme files to install.

johnson-cooper created this fork and handed it over to me; I maintain it now. Fixes from community forks get reviewed and credited when they're merged. Official builds are only on the Releases page.

POPSLoader

A browser and launcher for PS1 games on a PS2. It supports the original POPStarter and Sony POPS setup with VCD images, and Gageformer's Ember core as a separate, experimental emulator. You browse by storage device, launch games, and manage settings and artwork.

The project was started by israpps (El_isra). I work on the interface and put out the releases.

POPStarter is by krHACKen. A passing build doesn't prove a game works on a real console, so the repo keeps a hardware status page.

PS2-Servers

The PC side of playing PS2 games over your home network. It runs the servers that network-capable PS2 homebrew connects to, on Windows, Linux or macOS. It comes in three editions:

  • Desktop: an app with a tab for each server, a searchable game library and cover art conversion.
  • Core: the same Python servers, run from a terminal.
  • Edge: a separate Go server for routers, NAS boxes, Raspberry Pis and other headless machines.

Use the mode your PS2 app supports. Running a server doesn't teach an app a protocol it doesn't already speak.

FatBaldDad's PS2-EtherDrive hardware project plans to use it.

Smaller projects

  • launcHER

    A small forwarder that finds Ember wherever you keep it, prepares that storage device, hands Ember the game to launch, and then gets out of the way. Derived from the standalone launcher in pcm720's OSDMenu.

  • Simple Media System

    A maintained fork of Eugene Plotnikov's SMS media player: video, music, pictures, subtitles and playlists. It adds MX4SIO, exFAT HDD, i.LINK, MMCE and UDPFS support, DS3/DS4 controllers, and a desktop media converter.
